    ① Enviar backup (exportar)

    1. Clique em Baixar backup JSON.
    2. Envie o arquivo ao colega (WhatsApp, e-mail ou Drive).
    3. Ele importa no menu Backup do sistema dele.

    O JSON completo inclui tarefas, empresas, inventário e manutenções.

    ② Receber backup (importar)

    1. Peça o arquivo .json ao colega.
    2. Recomendado: baixe um backup dos seus dados atuais antes (passo ①).
    3. Clique em Escolher arquivo JSON e confirme a substituição.
    ⚠️ Importar substitui todos os dados deste navegador pelos do arquivo. Não dá para desfazer sem um backup anterior.

    Fluxo sugerido (Daniel ↔ Danilo)

    Quem atualizou por último exporta o JSON e envia.

    O outro importa esse arquivo no início do dia (ou antes de trabalhar).

    Evite os dois editarem ao mesmo tempo sem combinar quem é a “fonte da verdade” do dia.
